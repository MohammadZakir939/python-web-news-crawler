# Web News Crawler

A simple Python web crawler that searches selected websites for news articles based on a specific topic.

## Features

- Search for a specific topic
- Crawl multiple websites
- Limit crawling to selected websites
- Extract article titles and URLs
- Remove duplicate URLs
- Save results to a text file

## Technologies

- Python
- Requests
- BeautifulSoup
